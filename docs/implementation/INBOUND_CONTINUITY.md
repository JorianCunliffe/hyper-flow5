# Project clarification continuity

Project matching prefers a complete specific name over a shorter name contained in that same mention (for example Morning Run v2 over Morning Run). Separate mentions and identical aliases remain ambiguous; candidate projects are still permission-filtered first. Receptionist labels and aliases use the same matching rule.

SMS project clarification retains the source communication ID and candidate project IDs for 15 minutes, scoped to the tenant, verified person and receiving number. A short project-selection answer can recover that pending question even when Communications assigned a new thread because of an ambiguous ranking margin. The server rereads the source, verifies both participants, channel, receiving identity, dates and candidate scope, and uses the original question only as analysis input. It does not replay the original workflow event or merge provider threads. A new question mentioning a project is not treated as a selection-only answer. Successful reply clears the pending pointer without deleting communications or history.
